# Roadmap

This roadmap describes directions, not delivery promises. Changes to the protocol retain the project’s core principles: local-first defaults, deterministic facts, explicit security boundaries, and human judgment.

| Horizon | Focus                                                                              | Status                      |
| ------- | ---------------------------------------------------------------------------------- | --------------------------- |
| `0.1`   | Core receipt, CLI, static inspector, data-only policy, CI.                         | Shipped in this repository. |
| `0.2`   | Fixture corpus, receipt comparison, richer JUnit/SARIF metadata, and policy packs. | Planned.                    |
| `0.3`   | Signed receipt envelopes and verification-key management.                          | Research.                   |
| `0.4`   | GitLab/Forgejo adapters and optional self-hosted receipt registry.                 | Research.                   |

Potential features are assessed against privacy, replay safety, compatibility, and maintenance burden. An automated approval score, contributor surveillance, or hidden remote collection is outside the roadmap.
